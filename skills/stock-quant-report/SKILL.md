# 股票量化分析报告

输入美股代码（如 `NVDA`）或沪深 A 股代码（如 `600519`、`000001`）即可执行。支持同市场的多个代码，第一只为主要分析标的；美股默认加入 SPY，A 股默认加入 510300 沪深300ETF 作为基准与资产池成员。本技能自带分析引擎，不依赖原 GitHub 仓库的其他目录或作者电脑。

## 执行

将 `<skill-dir>` 替换为本 SKILL.md 所在目录的绝对路径，在用户当前工作目录运行：

```text
python "<skill-dir>/scripts/analyze.py" NVDA
```

脚本自动在当前工作目录的 `work/stock-quant-runtime` 创建独立 Python 环境并安装依赖，不修改全局 Python。需要 Python 3.11+ 和联网能力。Windows 也可使用可用的 `py -3`。若当前 Python 已具备所有依赖，可加 `--use-current-python`。

默认生成到当前工作目录的 `outputs/<代码>-quant-<UTC时间>/`，输出路径会打印在最后一行 JSON。若宿主指定了输出根目录，使用 `--output-dir` 指向其下的一个全新目录。不要把数据和虚拟环境写入安装的技能目录。

用户只提供代码时直接执行，默认最近五年、按市场选择基准、按时间顺序约 70% 训练和 30% 样本外测试、单边成本 10 bp；A 股股票卖出另计历史印花税。记录实际可用区间，不要求用户重复提供这些默认值。明确的日期、资产池、成本和机器学习要求优先；通用参数见 [参数与边界](references/methodology.md)；A 股的因子、无风险收益与执行限制见 [中国市场](references/china.md)。

```text
python "<skill-dir>/scripts/analyze.py" 600519
python "<skill-dir>/scripts/analyze.py" 000001 600519
python "<skill-dir>/scripts/analyze.py" NVDA MSFT --include-ml
python "<skill-dir>/scripts/analyze.py" AAPL --start 2020-01-01 --end 2026-07-31 --train-end 2023-12-31 --cost-bps 10
```

主要输出：独立 HTML 报告 `report.html`、Markdown `report.md`、`asset_overview.png`、CSV 明细、行情/因子快照、日期审计和来源指纹。

## 结果呈现

运行完成后读取最后一行状态和 `acquisition.json`，再检查报告与 `analysis/` 的实际结果。概括标的、分析区间、主要风险、因子解释度与 Alpha 显著性；若启用预测，必须同时报告朴素基线。

在宿主支持时打开生成的 HTML 报告预览。回复中提供报告链接并展示生成的资产净值图；图像与文件使用本次输出的绝对路径。不要只回复命令，也不要把因子数据截止日期描述成今日行情。用户要求分享技能不等于要求公开其生成报告或上传原始数据。

## 判断边界

- 美股使用 AKShare / 新浪，沪深 A 股使用 AKShare / 腾讯前复权行情；A 股交易日历来自新浪。复权与分红口径未独立验证。不得把这些价格收益直接称为已核验的含分红总收益。
- 官方美国 FF3 与 FF5 中 SMB 构造不同；五因子文件内的三项约束模型已命名 `FF3_restricted_FF5`。HAC、t、p、置信区间和显著性均由代码计算，不能编造。
- 缺失交易日、重复日期、无效价格或下载失败会明确报错；不填充、不截尾、不偷偷改用其他数据源。保留失败记录并解释具体原因；一次报告失败后最多针对暂时性网络故障重试一次，使用新输出目录。
- 样本不足时可能返回 `partial`：只报告已完成的风险与因子分析，并明确哪些组合/预测模块未运行。退出非零或出现 `failure.json` 时不宣称报告成功。
- 均线和预测信号留出下一收盘执行时间；组合只用训练数据估计。不要为了让回测更好看而在测试期反复选择参数。
- A 股默认仅做本地基准市场模型，无风险收益明确假设为 0，可指定 `--cn-rf-annual`。没有中国因子时必须说明三/五因子被跳过，不编造因子或调用美国文件。
- 中国代码支持 `600519`、`sh600519`、`600519.SH`、`000001.SZ`，六位 `000001` 表示深市股票而不是上证指数。不可在同一报告混合中国与美国资产。港股、北交所和加密资产尚不支持。
- A 股回测为日频研究近似：股票卖出有印花税，每个交易日最多一次调仓。必须说明尚未模拟涨跌停成交、停牌成交、整手与最低佣金，不能包装成可执行实盘业绩。
